New Video,
Step By Step.

From a finished video to the same video with Retro OS graphics and sound effects on top. You run five commands and ask Claude for one thing. Each step below says where the files go.

Step 0 · Once EverSetup

Make the retro command work everywhere

The tool lives in your main checkout of the repo. Pull it, then add one line to ~/.zshrc so retro works from any folder:

# get the latest main
cd ~/conductor/repos/davecto-cutroom && git pull

# add the alias (once), then open a new Terminal tab
echo 'alias retro="$HOME/conductor/repos/davecto-cutroom/retro/retro"' >> ~/.zshrc

It uses the tools Cutroom already installed (HyperFrames, Chromium, Whisper). If a command says something is missing, run node setup.mjs once in the repo folder.

Step 1 · Your VideoWhere It Goes

Put the finished video in video/

Export the final cut with all your edits and your voice, 9:16, ideally 4K. Drop it in the repo's video/ folder:

davecto-cutroom/
└── video/
    └── MyReel.mov        ← your video (git ignores video files automatically)

It can go anywhere, but keeping it in video/ means the project's notes and beats get saved in git next to the other videos (step 7).

Step 2 · New Project~1 Min

Run retro new

cd ~/conductor/repos/davecto-cutroom
retro new video/MyReel.mov

It transcribes the video, finds your face and the scene cuts, and makes a project folder next to the video:

video/
├── MyReel.mov
└── MyReel-retro/          ← the project: run every other command in here
    ├── retro.json         which beats are on, moves, sound levels
    ├── words.json         the transcript, with word timings
    ├── faces.json         where your face is, frame by frame
    ├── beats/             empty for now: Claude writes the animations here
    └── out/               renders appear here
Step 3 · AnimationsAsk Claude

Ask Claude to write the beats

Open Claude Code in the repo (or a Conductor workspace on it) and say something like:

› Add retro animations to video/MyReel-retro. Make them eye-catching
  and different from the last video.

Claude follows retro/GUIDE.md. It reads the transcript, splits it into beats (one idea each, a few seconds long) and writes one fresh animation per beat in beats/01-…/index.html, beats/02-…/ and so on. It checks placement against your face rules, renders, and looks at a few frames.

Things you can add to the ask: “use the Star Wars ships on the intro”, “make it teal”, “keep it sparse”, “more sound effects on the list part”.

Step 4 · Previewlocalhost:4180

Watch it, switch things off, move things around

cd video/MyReel-retro
retro preview

Open http://localhost:4180. The graphics and sounds play live over the video, with no render needed.

Spaceplay / pause (the bar under the video scrubs)
Click A Namejump to that beat
☑ Checkboxbeat on/off. Its sound effects go with it.
☑ ♪mute just that beat's sounds
Click A Layerthen drag on the video, or use the arrow keys (Shift = bigger steps). r resets it, Esc lets go.
Face Zoneshows the red no-go box around your face and chin

Every change saves to retro.json as you go. Ctrl-C in Terminal stops the preview.

Step 5 · ChangesTwo Ways

Change the look or the timing? Ask Claude. Small tweaks? Do it yourself.

Name the beat: “06: make the save dialog bigger”, “03 should land on ‘smarter’, not ‘ton’”, “redo 08, it's boring”. For quick tweaks, use the preview or these commands (run them in the project folder):

retro ls                     # every beat: on/off, times, layers, sounds
retro off 04                 # turn beat 04 off (and its sounds)
retro on 04
retro move 06 save 0 -5      # move beat 06's "save" layer up 5 (units = 1% of the width)
retro sfx 04 -4              # beat 04's sounds 4 dB quieter
retro sfx all -3             # all sound effects quieter
retro lint                   # anything over my face or under Instagram's buttons?
Step 6 · Render~3 Min

Make the final video

cd video/MyReel-retro
retro render

That writes out/MyReel-retro.mp4: 1440×2560 (Instagram 2K), with the graphics on top and the sound effects mixed under your voice. Upload that one.

  • retro render --draft renders faster at lower quality, for checking.
  • retro render --video ../MyReel-v2.mov puts the same graphics on a recoloured copy (the timing must be the same).
  • Only beats that changed get re-rendered, so the second render is quick.
  • On Instagram, turn on Upload at highest quality (Settings → Data usage and media quality).

Finishing in an editor instead? out/overlays/ has every beat as a transparent .mov, out/placements.csv says where each one starts, and out/sfx.wav is the sound effects on their own.

Step 7 · Keep ItOptional

Save the project in git

Commit the project folder (or ask Claude to merge it). Only the small files go in: beats/, retro.json, words.json and faces.json. Video files and out/ are ignored automatically, so you can't commit a 100MB file by accident.
